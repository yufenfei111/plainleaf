## 四、范围与平台要点

1. **iOS 本期不在范围内。** 经查 `ios/Runner/Info.plist`（经 `project.pbxproj` 引用）**未声明**
   `NSCameraUsageDescription` / `NSPhotoLibraryUsageDescription` 用途描述。
   做 iOS 前必须先在 Info.plist 补上相机/相册用途描述，否则相关权限请求会直接崩溃、且无法通过
   App Store 审核。Android 不受影响（运行时权限由插件处理）。
2. `flutter analyze` 在中文路径下会崩（项目路径含中文）：用 `dart analyze lib test`，
   或在 ASCII 路径副本里跑（沿用 W5 环境要点）。
3. `flutter test` 本机需去掉代理（否则 `flutter_tester` 的本地 WebSocket 被劫持）：
   `env -u HTTP_PROXY -u http_proxy -u HTTPS_PROXY -u https_proxy flutter test`。
4. 真机走查前请先确认 §一⚠️ 的 `/detail` 路由已由主代理注册，否则 D 类跳转无法验证。
